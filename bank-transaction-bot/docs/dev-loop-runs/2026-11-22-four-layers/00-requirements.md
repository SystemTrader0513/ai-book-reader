# Requirements Baseline
用户已批准上一轮提出的四层分离：独立映射、规则、披露与话术配置，同时保持可运行的本地网页。
Goal: 本体仅领域定义与动作适用关系；映射独立配置并真正执行；规则为受限 JSON 决策表；披露独立政策；中文回复集中模板。
Acceptance: 原有43测试继续通过；配置修改能改变映射/决策/话术；未知映射、非法规则与模板引用启动或调用时报错而非猜测；历史/当前、缺失/冲突与风险边界保留；压缩包在独立目录跑通。
Constraints: Python3.9+、无必装依赖、MOCK只读、原地保留既有工程、无提交/发布。
Assumptions: JSON替代YAML（同样分层）；四层业务定义不变；内部优先和产品规则不臆造。
Repo: unborn main，所有现有文件未追踪，不撤销已有内容。
Non-goals: 完整OWL DL、生产身份、真实银行或实际供应商集成。
