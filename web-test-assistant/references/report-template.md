# 网页测试结果报告

## 1. 执行摘要

Run ID、模式、总测试数、稳定通过率、需求覆盖率、发布建议。

## 2. 测试环境

环境名称、Base URL 和执行上下文。

## 3. 结果统计

列出 passed、failed、flaky、skipped、blocked、infrastructure_error。

## 4. 需求覆盖矩阵

需求 ID、聚合状态和关联测试。

## 5. 失败与阻塞详情

失败分类、脱敏后的错误信息和证据链接。

## 6. 证据与未映射测试

列出 trace、截图、视频和缺少需求 annotation 的测试。

## 7. 自动修复记录

每次 Heal 的类型、轮次和结果。

## 8. 未执行范围

未执行、澄清中或不支持的需求。

## 9. 残余风险与发布建议

列出残余风险并给出 release、review 或 do-not-release。
